Security fixes: PKCE DB storage + CRON_SECRET enforcement

Implemented two high-priority security fixes:

1. PKCE Code Verifier Database Storage (High Priority)
   - Moved PKCE verifiers from cookies to secure database storage
   - Added automatic expiration (10 minutes)
   - Implemented single-use enforcement
   - Created automated cleanup cron job (hourly)
   - Zero client-side exposure

2. CRON_SECRET Enforcement (Medium-High Priority)
   - Made CRON_SECRET required in production
   - Enforced authentication on all cron endpoints
   - Added security logging for unauthorized attempts
   - Minimum 32-character length validation
   - Startup validation to catch misconfigurations
