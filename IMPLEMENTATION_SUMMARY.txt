New Table: pkce_verifiers

CREATE TABLE "pkce_verifiers" (
  "state" text PRIMARY KEY NOT NULL,
  "code_verifier" text NOT NULL,
  "created_at" timestamp DEFAULT now() NOT NULL,
  "expires_at" timestamp NOT NULL
);

CREATE INDEX "pkce_verifiers_expires_at_idx" 
  ON "pkce_verifiers" ("expires_at");

Purpose: Securely store PKCE verifiers with automatic expiration
Size: < 10KB (max ~100 concurrent entries × 100 bytes)
Cleanup: Hourly via cron job
